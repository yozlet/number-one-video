# Shot manifest

Every image under `shots/` and `reference/extracted/frames/` is gitignored — it is derived from the copyrighted source video, large, and regenerable. This file is the recipe, so a reader can rebuild any of them and verify they got the same image.

**To rebuild a shot:** check out the commit in the *origin* column, run the command in *rebuild*, then compare the file's sha256 against the last column.

- `recorded @ <sha>` — written by `tools/prov.py` at generation time. Exact arguments, timings and source commit. `+dirty` means `index.html` or `tools/` had uncommitted changes, so the sha alone is not enough (re-render to be sure).
- `inferred (pre-git)` — produced before this repo existed. The filename pins the source time; the rest of the command is how that tool is invoked *today*, not a record of what was run. Treat it as a hint.
